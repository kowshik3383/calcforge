# Calculator content plan

[The keyword plan](calculator-keyword-plan.csv) proposes three search intents per calculator across 107 calculator pages. These are 321 editorial candidates, not 321 new publishing commitments. Some intents already have a CalcForge guide, identified in the reuse column.

1. **How to calculate.** Lead with the user's question, explain the formula and input units, and link to the calculator.
2. **Worked example.** Give a realistic set of inputs, show how the output was found, and explain how it changes the next decision.
3. **Input and rounding checks.** Explain what to measure, common unit mistakes or assumptions, and when the estimate stops applying.

Before publishing, set the target country and language in [Google Ads Keyword Planner](https://developers.google.com/google-ads/api/docs/keyword-planning/generate-historical-metrics) and collect monthly search estimates for query clusters. The CSV contains search-intent hypotheses. It contains no verified volume, difficulty, or ranking claims.

Review the search results for each query. When several phrases return the same kinds of pages, assign them to one guide. Update and link existing guides first. Publish a separate example or troubleshooting guide only if readers need a different answer. Give both directions a relevant internal link, from guide to tool and from tool to guide. Engineering and animal-care topics need relevant primary sources and subject-matter review before publication.
