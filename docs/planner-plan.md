# MeasureForge planner plan

The calculators answer a single measurement question. Planners combine the inputs and results for a job or practice session. Resuming a saved project is the first return-visit feature. Each planner has three steps and a print layout.

| Planner | Enter details | Review | Save and revisit |
| --- | --- | --- | --- |
| Flooring and tile | Add rooms, adjoining rectangles, exclusions and product quotes | Compare room sketches, boxes, leftover coverage and delivered cost | Save the job or print a supplier shopping list |
| Indian land and plots | Add listings with frontage, rear width, depth and a survey reference | Compare plot sketches and common regional units, or use a documented local unit factor | Save a group of listings and print the measurement sheet |
| Workshop | Enter cut dimensions, grain direction, stock, offcuts and hardware | Inspect shelf layouts with blade kerf, material and hardware cost, and reusable rectangular offcuts | Save each job and print cut, stock and hardware lists |
| Garden | Add beds, crops, dates, spacing, and soil and mulch depths | Inspect planting grids, seed counts and material totals | Save planting notes and revisit or print the record |
| Archery | Select a target round preset and enter arrow scores by end | See running totals, saved practice rounds and the personal best for a complete round | Save practice, print a scorecard or share text with a club |

## Release sequence

1. Publish the planner index and five individual pages. Connect existing calculator categories to the relevant planner and include the new URLs in the sitemap.
2. Validate one realistic estimate per planner, invalid inputs, save and reopen, and print. Check archery sharing and complete-round personal bests separately.
3. Use Search Console to see which planner entry pages gain impressions and clicks. Review queries before creating new guides. Use feedback about real jobs to decide which planner to expand.
4. Evaluate optional cross-device sync, fuller stock inventory, and club leaderboards once usage justifies accounts and storage.

## Model limits

Flooring sketches use a main rectangle, one adjoining rectangle, and one rectangular exclusion. Plot area assumes parallel front and rear boundaries and perpendicular depth. Regional unit names can vary by locality. Workshop layouts are estimates from a shelf packing method, so check the layout and measurements before cutting. Garden beds use rectangular spacing grids. Archery presets are practice scorecards and saved results are stored on the current device.
